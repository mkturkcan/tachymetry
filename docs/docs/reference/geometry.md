# `tachymetry.geometry`

Camera model, lens models, planar homographies and box silhouettes for the mask geometry ([Vehicle footprints from masks](../guide/footprints.md)). Conventions (pixel origin, world frame, angles) are stated in the module docstring of `tachymetry.geometry.camera` and summarised in [Calibration](../guide/calibration.md); the lens models are derived in [Lens models](../guide/lens-models.md).
