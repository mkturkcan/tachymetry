# Citation

If you use Tachymetry in your research, please cite it:

```bibtex
@software{turkcan2026tachymetry,
  author  = {Turkcan, Mehmet Kerem},
  title   = {{Tachymetry}: Clean Metric Trajectories, Speeds and Counts from Traffic-Camera Video},
  year    = {2026},
  url     = {https://github.com/mkturkcan/tachymetry}
}
```

Results obtained with the default detector should also credit [UrbanOmniDetect-2](https://huggingface.co/mehmetkeremturkcan/UrbanOmniDetect-2); see its model card for the reference.

## Sample footage

The demo and the figures in this documentation use clips from [svbrd-llm-roadside-video-av](https://huggingface.co/datasets/Ryan-xiangyu-ut/svbrd-llm-roadside-video-av) by Ryan-xiangyu-ut on Hugging Face, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The clips are downloaded on demand and not redistributed with Tachymetry; figures show frames with Tachymetry's overlays added.
